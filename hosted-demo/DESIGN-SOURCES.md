# Design sources

- Brand typography: https://openai.com/brand/ (OpenAI Sans).
- Font files: https://github.com/openai/model_spec/tree/main/docs/fonts
  (Regular, Semibold and Bold WOFF2 assets).
- OpenAI's public developer documentation also links a downloadable OpenAI Sans
  resource: https://developers.openai.com/api/docs/guides/custom-chatkit#design-resources
- Neutral color tokens: https://github.com/openai/apps-sdk-ui/blob/main/src/styles/variables-primitive.css
  Text #0d0d0d, muted text #5d5d5d, background #f9f9f9, cards #ffffff,
  borders #dfdfdf, secondary surfaces #ededed.

The site uses these public typography and color resources for the workshop design.
